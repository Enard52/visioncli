Your screen, understood.

Everything happens on your computer, with the AI you already use.

Hold a key, ask

Hold ⌥ / Alt and ask out loud. Add ⌘ / Win to include a screenshot. The answer appears in a bubble and is read aloud.

Sees what you mean

"What is this file for?" It looks at the window under your mouse, finds the real file in your project and answers with file:line references.

Uses your computer

Clicks, types and opens apps one checked step at a time. You approve each action, passwords always ask, and Esc stops it instantly.

Points and draws

Answers draw boxes, arrows and numbered steps on your real screen, and can include Mermaid diagrams.

Fast browser control

"Open the Stripe tab", "find a stay in Lisbon with a pool": quick commands and multi-step tasks in Chrome, Brave and Edge.

Local voices

Parakeet and Whisper transcription and Kokoro voices run on your machine. Your audio isn't sent anywhere.

Download VisionCLI

Free and open source (MIT). Version 0.10.4.

macOS 13 or later

Download .dmg
brew install --cask thethirdsourcers/tap/visioncli

VisionCLI isn't notarized by Apple yet, so macOS asks before the first launch: System Settings → Privacy & Security → Open Anyway, or run xattr -dr com.apple.quarantine /Applications/VisionCLI.app.

Windows 10 / 11 (x64 and Arm)

Installer x64 Installer Arm64 
winget install TheThirdSourcers.VisionCLI

Installs for your user only, no admin rights.

Linux (x86_64 and arm64)

AppImage x86_64 AppImage arm64 .deb amd64 .deb arm64 .rpm x86_64 .rpm aarch64

Debian / Ubuntu (apt repository, updates with the system):

curl -fsSL https://visioncli.thethirdsourcers.com/public.key | sudo gpg --dearmor -o /usr/share/keyrings/visioncli.gpg
echo "deb [signed-by=/usr/share/keyrings/visioncli.gpg] https://visioncli.thethirdsourcers.com stable main" | sudo tee /etc/apt/sources.list.d/visioncli.list
sudo apt update && sudo apt install visioncli-linux

Fedora / RHEL / openSUSE (dnf or zypper repository):

sudo curl -fsSL -o /etc/yum.repos.d/visioncli.repo https://visioncli.thethirdsourcers.com/visioncli.repo
sudo dnf install visioncli-linux

Then start VisionCLI from your app menu; its setup wizard checks the desktop tools it needs. Details in docs/LINUX.md.

Code signing policy

Windows releases: free code signing provided by SignPath.io, certificate by SignPath Foundation.

Every release is built by GitHub Actions from this public repository; nothing is built or signed on a personal machine. Committers and reviewers: the maintainers of thethirdsourcers on GitHub. Approver for each signed release: Manjit Shakya (Third Sourcers). See also the privacy policy.

Check a download

Every file is listed in SHA256SUMS.txt and carries a build provenance attestation from the GitHub workflow that built it:

gh attestation verify VisionCLI-0.10.4-macos.dmg -R thethirdsourcers/visioncli
